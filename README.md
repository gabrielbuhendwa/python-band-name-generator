Python Band Name Generator

A simple Python command-line application that generates a potential band name based on two pieces of information provided by the user: the city they grew up in and their pet's name.

This project is my first Python challenge and serves as an initial exercise in working with user input, variables, and string manipulation.

Overview

The Band Name Generator collects information from the user through the terminal and combines the provided city and pet name to generate a suggested band name.

The project focuses on applying basic Python syntax and concepts in a small, functional program.

Technologies
Python 3
Command Line Interface

No external dependencies are required.

Concepts Demonstrated
User input with input()
Output with print()
Variables
String concatenation
Basic command-line interaction
